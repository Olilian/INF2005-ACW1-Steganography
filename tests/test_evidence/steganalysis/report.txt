READING THIS: p near 1 = this region's histogram already looks 'equalised'
between adjacent byte-value pairs -- the LSB-replacement fingerprint. p near
0 = looks like natural, untouched data.

WHY THREE TESTS: the whole-file test (1) correctly finds nothing at low LSB
depths, because a2_crypto's keyed placement only touches a small fraction of
a large cover -- that is the honest limit of global steganalysis against
small, localised payloads, not a broken test. The naive sliding window (2) is
shown flagging a large fraction of windows even in the UNTOUCHED cover --
real photographic texture (narrow local tone ranges) starves small windows
of distinct values and destabilises the statistic, which is a genuine
limitation of that test on real images, not on this LSB scheme. The
differential test (3) fixes that by comparing each window against the same
position in the known clean cover, cancelling the texture noise -- its own
honest limitation is that it needs that clean reference, which a real
attacker analysing an unknown file in isolation usually will not have.
